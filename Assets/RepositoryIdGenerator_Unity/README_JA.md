# Repository ID Class Generator（Unity Editor 専用）

リポジトリCSVの `id` 列から、指定したID型の `public static readonly` フィールドを持つ `partial class` のC#ファイルを生成します。

## 導入

`Assets/Editor/RepositoryIdGenerator/` フォルダを、Unityプロジェクトの同じ場所にコピーしてください。

**ID型と生成先クラスは、Editorフォルダではなく通常のコード配置場所に置いてください**（ランタイムで使用する場合）。

## 準備

例えば `Assets/Scripts/SoundIds.cs` に、次のように生成先クラスを宣言します。

```csharp
public static partial class SoundIds
{
}
```

ID型の `SoundId` は既存クラスを利用します。生成コードで `new SoundId("warning")` を呼び出せることを前提とし、専用インターフェース・基底クラス・ファクトリーは要求しません。

## 操作手順

1. Unityで `Assets > Create > Tools > Repository ID Generation Config` を選び、設定アセットを作成します。
2. 設定アセットを選択し、Inspectorの **Repository CSV > Browse...** でCSVを選びます。`Assets` の外にあるCSVも指定できます。
3. **ID Type (Script)** に `SoundId.cs` をドラッグ＆ドロップします。
4. **Target Class (Script)** に `SoundIds.cs` をドラッグ＆ドロップします。
5. **Generate ID Class** を押します。

選択中の設定アセットに対して `Tools > Repository > Generate ID Class` から実行することもできます。

出力先は生成先クラスと同じフォルダです。上記例では `Assets/Scripts/SoundIds.g.cs` が作成されます。手書きの `SoundIds.cs` は変更しません。

## 入力例

```csv
id,path
warning,sounds/warning.wav
notification,sounds/notification.wav
startup,sounds/startup.wav
```

## 出力例

```csharp
// <auto-generated />
// Generator: RepositoryIdGenerator
// Do not edit this file. Regenerate it from the config asset.
public static partial class SoundIds
{
    public static readonly global::SoundId warning = new global::SoundId("warning");
    public static readonly global::SoundId notification = new global::SoundId("notification");
    public static readonly global::SoundId startup = new global::SoundId("startup");
}
```

CSVのIDはフィールド名としてそのまま使用し、PascalCase変換などを行いません。`bad-id` や `class` のようにC#フィールド名にできないID、重複ID、空欄IDは**エラーにして生成しません**。

## 制約・注意事項

- 生成先は、トップレベルの非ジェネリック `partial class` としてください。`static` / `sealed` / `abstract` は対応します。
- ID型もオープンジェネリックではないクラスを指定してください。文字列引数で呼び出せる適切なコンストラクタがあるものとします。
- ファイル選択はOS標準ダイアログ、型指定は `MonoScript` のドラッグ＆ドロップで行います。
- 既存の生成ファイルが同じ内容なら書き換えません。本ジェネレーターの識別ヘッダーがないファイルは上書きしません。
- `partial` であるかどうかは `MonoScript.GetClass()` のリフレクションでは判定できません。指定した手書きファイルに `partial` がなければ、生成後にC#のコンパイルエラーになります。
- CSVはUTF-8を想定します。ダブルクォートによるセルの囲み、カンマ、改行を含むセルに対応します。
- 元のCSVのファイルパス変更だけなら、IDフィールドの生成結果は変わりません。リポジトリの実行時ファイル解決は従来どおり別責務です。
- 1つの設定アセットが1組のCSV・ID型・生成先クラスに対応します。複数の対象がある場合はアセットを複数作成します。

このパッケージは、本環境ではUnity Editor上での実コンパイル・動作確認を実施していません。導入後、既存のID型・生成先クラスと合わせて検証してください。
