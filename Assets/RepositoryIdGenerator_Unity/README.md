# Repository ID Class Generator (Unity Editor)

A Unity Editor-only CSV -> C# partial class generator. Supports Unity 6 / C# 9; no runtime dependency.

## Install

Copy `Assets/Editor/RepositoryIdGenerator/` into your project's `Assets/Editor/RepositoryIdGenerator/`. Do not put the ID value-object classes or target classes in the Editor directory unless they are intended to be editor-only.

## Prepare the target class

For example, in `Assets/Scripts/SoundIds.cs`:

```csharp
public static partial class SoundIds
{
}
```

Assumed `SoundId` class has a constructor callable as `new SoundId(string)` (the generator does not force inheritance, an interface, or a factory method). You can freely add other constructors and members.

## Use

1. In Unity, `Assets > Create > Tools > Repository ID Generation Config` creates a config asset.
2. Select the config asset in the Inspector.
3. Choose the repository CSV with **Browse...** (files outside `Assets` work).
4. Drag `SoundId.cs` into **ID Type (Script)**.
5. Drag `SoundIds.cs` into **Target Class (Script)**.
6. Press **Generate ID Class**. Alternatively, while the config is selected, use `Tools > Repository > Generate ID Class`.

The generated file is written alongside the target class, e.g. `Assets/Scripts/SoundIds.g.cs`. Run again after ID additions/deletions/renames. The generator does not edit the hand-written `SoundIds.cs`.

## CSV

The CSV must be UTF-8 with an `id` header; extra columns are ignored:

```csv
id,path
warning,sounds/warning.wav
notification,sounds/notification.wav
startup,sounds/startup.wav
```

Generated code:

```csharp
// <auto-generated />
// Generator: RepositoryIdGenerator
// Do not edit this file. Regenerate it from the config asset.
public static partial class SoundIds
{
    public static readonly global::SoundId warning = new global::SoundId("warning");
    public static readonly global::SoundId notification = new global::SoundId("notification");
    public static readonly global::SoundId startup = new global::SoundId("startup");
}
```

## Behavior / limitations

- No automatic PascalCase conversion or other ID renaming. IDs must already be valid C# field identifiers; reserved keywords, duplicates, blanks, and collisions with the containing class name cause an error.
- The target must be a **top-level, non-generic, partial class**. The selected `.cs` must be in `Assets` and must not itself be a generated `.g.cs` file. The generated file is placed in the same directory to help ensure the same Unity assembly.
- The ID type must be a non-open-generic C# class. It can be a plain C# class and does not need to derive from anything or implement an interface; it must be callable from the generated code as `new IdType("...")`.
- CSV parsing supports quoted cells, escaped double quotes, and CRLF/LF.
- Existing `.g.cs` files that lack this generator's marker are never overwritten. Identical generated content is not rewritten.
- The target script must already compile and declare `partial`. Reflection cannot detect the `partial` modifier; if missing, Unity compilation will report an error when the generated file is imported.
- Because C# static fields are initialized once per process, regenerated IDs do not dynamically reflect CSV updates in a standalone build. CSV paths remain resolved by your existing repositories at runtime.
- A new ID can be generated from a CSV outside the Unity project; generating a class does not automatically bundle that CSV or its referenced content into builds.

## Suggested sanity checks

1. Basic CSV: create three IDs -> three fields, use IDE completion.
2. Rename one CSV ID -> regenerate; old field disappears and new field appears.
3. Add `id` value `bad-id` -> generation fails without renaming or touching previous output.
4. Duplicate `id` -> generation fails without changing output.
5. Use namespaced ID and target classes -> output compiles without extra `using` statements.
6. Change only `path` columns -> generated source remains unchanged (no content rewrite).
7. Repeat generation -> source content remains unchanged.
8. Place an unmarked `SoundIds.g.cs` file at destination -> overwrite blocked.

> Note: this package has not been compiled in a live Unity project in this environment. Unity integration and your existing classes should be validated inside the target project.
